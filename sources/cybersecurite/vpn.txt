# Matière : Cybersécurité
# Paquet : VPN

Qu'est-ce qu'un VPN ? ; Un Virtual Private Network relie deux points à travers un réseau non maîtrisé (souvent Internet) en simulant une liaison privée directe.
Quels sont les deux usages courants d'un VPN ? ; L'accès distant (un poste rejoint le réseau de l'entreprise) et le site à site (deux passerelles relient en permanence deux réseaux privés distants).
Quelle différence entre Intranet VPN et Extranet VPN ? ; Les deux sont du site à site. L'Intranet VPN relie deux sites d'une même entreprise et l'Extranet VPN relie l'entreprise à un partenaire.
Que se passe-t-il sans VPN pour un poste hors du réseau local ? ; Il est traité comme n'importe quel hôte d'Internet, sans accès aux fichiers, applications métier ou services internes non publiés.
Quelles trois garanties un tunnel VPN doit-il apporter ? ; L'authentification des deux extrémités, la confidentialité du contenu (chiffrement) et son intégrité (détection de toute altération en transit).
Quels prérequis pour un tunnel WireGuard ? ; Deux machines Linux avec wireguard-tools, une IP publique joignable en UDP sur au moins un point (le serveur) et ip_forward activé sur les passerelles pour du site à site.
Comment installer WireGuard sur Debian ou Ubuntu ? ; sudo apt update puis sudo apt install wireguard.
Comment générer une paire de clés sur une passerelle ? ; wg genkey | sudo tee /etc/wireguard/privatekey | wg pubkey | sudo tee /etc/wireguard/publickey, puis sudo chmod 600 /etc/wireguard/privatekey.
Quelle clé communique-t-on à l'autre passerelle ? ; Uniquement la clé publique, par un canal de confiance hors tunnel. Transmettre une clé privée reviendrait à donner l'identité complète du point qu'elle authentifie.
Quelles sections contient le fichier /etc/wireguard/wg0.conf ? ; [Interface] avec PrivateKey, Address et ListenPort (côté serveur), puis [Peer] avec PublicKey et AllowedIPs, plus Endpoint côté client.
Quelle est la double fonction de AllowedIPs ? ; Filtrer les paquets acceptés depuis ce pair et servir de route vers le réseau distant une fois l'interface active.
À quoi sert le paramètre Endpoint ? ; Il donne l'adresse IP publique et le port du serveur à joindre. On le renseigne côté client, par exemple 203.0.113.2:51820.
Comment activer le transfert IP de façon persistante pour WireGuard ? ; sudo sysctl -w net.ipv4.ip_forward=1 puis écrire net.ipv4.ip_forward=1 dans /etc/sysctl.d/99-wireguard.conf.
Quelle commande active et démarre le tunnel ? ; sudo systemctl enable --now wg-quick@wg0.
Que fait wg syncconf par rapport à wg-quick down puis up ? ; Il recharge la configuration sans couper les tunnels déjà établis avec les autres pairs.
Qu'est-ce qu'un split tunnel ? ; Avec AllowedIPs = 192.168.10.0/24, seul le trafic vers le LAN de l'entreprise passe dans le tunnel et le reste d'Internet sort directement.
Que provoque AllowedIPs = 0.0.0.0/0 sur un poste nomade ? ; Tout le trafic, navigation Internet comprise, passe par le VPN. C'est utile pour l'inspecter mais cela consomme la bande passante VPN et ralentit les usages non liés au travail.
Comment supprimer complètement le tunnel WireGuard d'une passerelle ? ; sudo systemctl disable --now wg-quick@wg0 puis sudo rm /etc/wireguard/wg0.conf.
Comment retirer un seul pair sans couper le reste du tunnel ? ; sudo wg set wg0 peer suivi de la clé publique du pair puis remove.
Pourquoi retirer un pair ne suffit-il pas si sa clé est compromise ? ; Sa clé privée reste valide si elle a été copiée ailleurs. Il faut régénérer une nouvelle paire de clés sur la machine concernée.
Comment vérifier l'état du tunnel ? ; sudo wg show affiche pour chaque pair le dernier handshake (latest handshake) et le volume transféré. Une entrée sans latest handshake indique un tunnel jamais établi.
Comment constater que le trafic qui transite par Internet est chiffré ? ; Capturer sur l'interface physique avec sudo tcpdump -n -i eth0 udp port 51820. Seuls des paquets UDP chiffrés vers le port 51820 apparaissent.
Que faire si wg show n'affiche aucun latest handshake ? ; Le port UDP 51820 est peut-être bloqué par un pare-feu ou la clé publique est mauvaise. Vérifier l'ouverture du port côté serveur et comparer les clés publiques des deux côtés.
Que faire si le handshake est établi mais qu'aucun ping ne passe ? ; AllowedIPs ne couvre pas le réseau distant ou ip_forward est désactivé. Vérifier AllowedIPs sur les deux pairs et sysctl net.ipv4.ip_forward.
Pourquoi le tunnel fonctionne-t-il puis se coupe-t-il après quelques minutes ? ; Un pair est derrière un NAT sans PersistentKeepalive. Ajouter PersistentKeepalive = 25 côté pair derrière le NAT.
Pourquoi un poste nomade perd-il tout accès Internet normal ? ; AllowedIPs = 0.0.0.0/0 alors qu'un tunnel partagé était prévu. Restreindre AllowedIPs au seul sous-réseau de l'entreprise.
Pourquoi un ancien poste supprimé se connecte-t-il encore ? ; Sa clé publique a été retirée côté serveur mais le service n'a pas été rechargé. Utiliser wg syncconf ou systemctl restart wg-quick@wg0.
Comment traiter une clé privée compromise ? ; Comme un incident de sécurité : l'exposition dure jusqu'à ce que le pair soit retiré et que l'entrée associée disparaisse de la configuration de l'autre extrémité.
