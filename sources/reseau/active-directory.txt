# Matière : Réseau
# Paquet : Active Directory

À quoi sert un annuaire Active Directory ? ; Il centralise l'identification et l'authentification d'un parc Windows dans un annuaire unique, plutôt qu'une base de comptes locale par machine (modèle « groupe de travail », base SAM).
Que regroupe un domaine Active Directory ? ; Des utilisateurs, groupes et ordinateurs dans une arborescence d'unités d'organisation (OU), avec des stratégies de sécurité appliquées via des GPO.
Pourquoi avoir plusieurs contrôleurs de domaine ? ; L'annuaire est répliqué entre eux, donc la disponibilité du domaine ne dépend plus d'un seul serveur.
Qu'est-ce que le DistinguishedName d'un objet AD ? ; C'est son chemin LDAP dans l'annuaire, par exemple cn=Pierre,ou=Informatique,dc=galaxy-swiss,dc=com. Il change si l'objet est déplacé.
Qu'est-ce que le GUID d'un objet AD ? ; Un identifiant sur 128 bits attribué à la création, qui est invariable.
Que détermine l'étendue d'un groupe ? ; Où il peut être utilisé : domaine local, globale ou universelle. C'est elle qui structure la méthode AGDLP.
Sur quel port et avec quel protocole un poste s'authentifie-t-il auprès d'un contrôleur de domaine ? ; Via LDAP sur le port 389 en clair, ou 636 en LDAPS (chiffré).
Quelle commande PowerShell crée une unité d'organisation ? ; New-ADOrganizationalUnit avec -Name et -Path, et -ProtectedFromAccidentalDeletion $true.
Pourquoi préciser -ProtectedFromAccidentalDeletion en PowerShell ? ; Une OU créée depuis la console graphique est protégée contre la suppression accidentelle, mais en PowerShell ce n'est pas automatique sans ce paramètre explicite.
Quelle commande PowerShell crée un compte utilisateur AD ? ; New-ADUser, avec notamment -SamAccountName, -UserPrincipalName, -Path, -AccountPassword, -ChangePasswordAtLogon et -Enabled $true.
Pourquoi un compte créé en PowerShell ne peut-il pas ouvrir de session ? ; Il est désactivé par défaut. Sans -Enabled $true, le compte existe mais ne peut pas s'authentifier, contrairement à un compte créé depuis la console dsa.msc.
Comment activer un compte AD créé sans -Enabled $true ? ; Avec la commande Enable-ADAccount -Identity suivie du nom du compte.
Que signifie la méthode AGDLP ? ; Account, Global Group, Domain Local Group, Permissions. C'est la méthode recommandée par Microsoft pour attribuer les droits.
Que représente un groupe global et un groupe de domaine local en AGDLP ? ; Un groupe global représente la fonction métier, un groupe de domaine local représente l'accès à une ressource.
Sur quel type d'objet pose-t-on les permissions NTFS en AGDLP ? ; Uniquement sur le groupe de domaine local, jamais directement sur un utilisateur ni sur un groupe global.
Quel est l'avantage de la méthode AGDLP quand un utilisateur change de service ? ; Il suffit de le changer de groupe global, sans jamais retoucher les permissions posées sur la ressource.
Quelle commande ajoute un membre à un groupe AD ? ; Add-ADGroupMember avec -Identity (le groupe) et -Members.
Quelle commande attribue une permission NTFS en lecture à un groupe sur un dossier ? ; icacls suivi du chemin, de /grant et du groupe avec la permission (RX), par exemple icacls "D:\Partages\Compta" /grant "GALAXY-SWISS\GDL_Partage_Compta_Lecture:(RX)".
Comment créer et lier une GPO à une OU en PowerShell ? ; Avec New-GPO -Name suivi de New-GPLink -Target désignant l'OU.
Où configure-t-on les paramètres d'une GPO ? ; Dans la console gpmc.msc, sous Configuration utilisateur ou Configuration ordinateur selon la cible.
Que signifie LSDOU ? ; L'ordre d'application d'une GPO : Local, Site Active Directory, Domaine, Unité d'organisation.
Que se passe-t-il quand deux GPO ont des paramètres contradictoires ? ; C'est la dernière appliquée, donc la plus proche de l'objet (en général l'OU), qui l'emporte.
Quelles commandes forcent et vérifient l'application d'une GPO sur un poste ? ; gpupdate /force pour forcer, gpresult /r pour vérifier.
Que prouve gpresult /r ? ; Il liste les GPO réellement appliquées à l'utilisateur et à l'ordinateur, preuve qu'une GPO liée à l'OU est bien descendue jusqu'au poste.
Pourquoi une GPO n'apparaît-elle pas appliquée sur le poste ? ; L'intervalle d'actualisation (60 à 120 minutes) n'est probablement pas encore écoulé. Lancer gpupdate /force sur le poste client.
Comment vérifier que deux contrôleurs de domaine partagent le même annuaire ? ; Avec repadmin /replsummary. Résultat attendu : Largest Delta proche de zéro et aucune erreur de réplication.
Que faire si repadmin /replsummary signale une erreur entre deux contrôleurs ? ; La réplication est en échec (réseau, DNS ou service arrêté). Lancer repadmin /showrepl sur chacun des deux contrôleurs pour isoler la cause.
Pourquoi Remove-ADOrganizationalUnit échoue-t-il avec « accès refusé » ? ; Car ProtectedFromAccidentalDeletion est toujours activé, ce qui est volontaire. Il faut d'abord lancer Set-ADOrganizationalUnit avec -ProtectedFromAccidentalDeletion $false.
Pourquoi un utilisateur accède-t-il encore à une ressource après avoir quitté le service ? ; Il est toujours membre du groupe global associé. Le retirer de ce groupe, sans toucher aux permissions NTFS.
Pourquoi des applications comme GLPI, un pare-feu ou un VPN utilisent-elles LDAP ? ; Pour authentifier leurs utilisateurs contre l'annuaire plutôt que de maintenir leur propre base de comptes.
