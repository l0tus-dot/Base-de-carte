# Matière : Réseau
# Paquet : NAT et PAT

À quoi servent le PAT et le NAT statique ? ; Le PAT permet à un réseau privé d'atteindre l'extérieur derrière une seule adresse publique. Le NAT statique ou la redirection de port expose un serveur interne depuis l'extérieur.
Quels prérequis faut-il pour configurer NAT et PAT ? ; Un routeur de bordure avec une interface LAN et une interface WAN, un routage interne déjà fonctionnel et une route par défaut vers le fournisseur d'accès.
Comment marquer les interfaces pour le NAT sur Cisco ? ; ip nat inside sur l'interface côté LAN et ip nat outside sur l'interface côté WAN, pour que le routeur sache de quel côté se trouve le réseau à traduire.
Quelle est la cause la plus fréquente d'un NAT qui ne traduit rien ? ; Un ip nat inside ou un ip nat outside oublié. show ip nat statistics affiche les interfaces retenues et, si la liste est vide, c'est là qu'il faut regarder.
Comment définit-on le trafic à traduire pour le NAT ? ; Avec une ACL standard comme access-list 1 permit 192.168.10.0 0.0.0.255.
Quel masque utilise une ACL et que vaut un /24 ? ; Un masque générique (wildcard), inverse du masque de sous-réseau, donc 0.0.0.255 pour un /24.
Quelle commande active le PAT sur l'interface WAN ? ; ip nat inside source list 1 interface GigabitEthernet0/0 overload. Toutes les machines du LAN sortent derrière l'adresse WAN, différenciées par le port source.
Quel mot-clé distingue le PAT du NAT dynamique ? ; Le mot-clé overload. Sans lui, il faut autant d'adresses publiques que de machines simultanées.
Quand utiliser le NAT dynamique avec un pool ? ; Quand plusieurs adresses publiques sont disponibles, avec ip nat pool puis ip nat inside source list 1 pool PUBLIC overload.
Comment exposer entièrement un serveur interne avec un NAT statique ? ; Avec ip nat inside source static suivi de l'adresse privée puis de l'adresse publique. Le serveur est alors joignable sur tous ses ports, à réserver aux cas réellement nécessaires.
Quelle forme d'exposition de serveur faut-il privilégier et pourquoi ? ; La redirection de port avec ip nat inside source static tcp et le port, par exemple 443, car elle réduit la surface exposée.
Quelles commandes configurent le NAT sous Linux avec iptables ? ; sysctl -w net.ipv4.ip_forward=1 puis iptables -t nat -A POSTROUTING -o ens18 -s 192.168.10.0/24 -j MASQUERADE.
Comment rendre le transfert IP persistant sous Linux ? ; sysctl -w ne survit pas au redémarrage. Il faut écrire net.ipv4.ip_forward=1 dans /etc/sysctl.d/99-routeur.conf puis lancer sysctl --system.
Dans quel ordre retirer une configuration NAT sur Cisco ? ; D'abord les règles de traduction, puis l'ACL, puis les marquages inside et outside, pour ne jamais laisser une interface marquée sans règle associée.
Comment couper immédiatement les traductions NAT en cours ? ; Avec clear ip nat translation *, car sinon les traductions restent actives jusqu'à expiration.
Que supprime nft delete table ip nat ? ; La table entière donc toutes les règles NAT qu'elle contient. Pour retirer une seule règle, utiliser nft delete rule avec son handle obtenu par nft -a list table ip nat.
Comment retirer une règle iptables ajoutée avec -A ? ; Avec -D en reprenant exactement les mêmes paramètres que ceux de l'ajout.
Quel est l'effet du retrait du NAT/PAT sur le trafic ? ; Les machines du LAN ne peuvent plus atteindre l'extérieur avec une adresse privée, il faut prévenir les utilisateurs avant de le faire hors fenêtre de maintenance.
Quelles commandes vérifient le NAT sur Cisco ? ; show ip nat translations et show ip nat statistics. En PAT, les ports source figurent après l'adresse, par exemple 192.168.10.10:1234.
Pourquoi utiliser debug ip nat avec précaution ? ; Il génère une ligne par paquet traduit et peut saturer le processeur d'un routeur chargé. Il est réservé aux tests et toujours suivi de undebug all.
Que faire si show ip nat translations reste vide ? ; Un ip nat inside ou outside est probablement manquant, à vérifier avec show ip nat statistics.
Que faire si la traduction est créée mais qu'il n'y a pas de réponse ? ; La route par défaut est probablement absente, il faut ajouter ip route 0.0.0.0 0.0.0.0 vers la passerelle.
Que faire si le LAN sort mais que le serveur publié reste injoignable ? ; La redirection est peut-être sur le mauvais port ou une ACL entrante bloque. Contrôler la règle statique puis show access-lists.
Que faire si une ancienne traduction persiste après un changement ? ; Ce sont des entrées en cache, il faut lancer clear ip nat translation *.
Que signifie un seul poste qui sort à la fois ? ; Le mot-clé overload a été oublié, il faut reprendre l'étape d'activation du PAT.
