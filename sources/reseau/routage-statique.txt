# Matière : Réseau
# Paquet : Routage statique

Dans quel cas utilise-t-on le routage statique ? ; Pour faire communiquer deux réseaux locaux séparés par une liaison entre routeurs, sans protocole dynamique, sur une infrastructure de petite taille dont la topologie ne change pas.
Quels équipements et accès faut-il pour configurer du routage statique ? ; Deux routeurs Cisco (IOS 15.x ou plus récent) avec accès console ou SSH en mode privilégié, et des interfaces adressées et actives.
Quelle commande active une interface Cisco désactivée administrativement ? ; no shutdown.
Pourquoi no shutdown n'est-il pas optionnel ? ; Une interface laissée désactivée n'apparaît pas dans la table de routage, c'est la première cause du problème « la route ne remonte pas ».
Quelle est la syntaxe d'une route statique Cisco ? ; ip route suivi du réseau de destination, du masque, puis de l'adresse du prochain saut.
Sur quel routeur ajoute-t-on la route par défaut ? ; Uniquement sur le routeur de bordure, pour tout ce qui n'est pas connu localement.
Quelles commandes enregistrent la configuration sur un routeur Cisco ? ; end puis copy running-config startup-config.
Que faut-il vérifier avant de retirer une route statique ? ; Que du NAT ou une ACL ne s'appuie pas dessus, avec show ip route et show running-config | include ip route.
Quelles commandes Cisco vérifient une route statique ? ; show ip route static, show ip interface brief, ping avec source et traceroute.
Comment une route statique apparaît-elle dans show ip route ? ; Préfixée par S, ou S* pour la route par défaut, avec une distance administrative de 1.
Quelles commandes de vérification existent sous Linux ? ; ip route show, ping -c 4 et traceroute.
Quelles commandes de vérification existent sous Windows ? ; route print, Test-NetConnection et tracert.
Quelle est la cause probable si la route n'apparaît pas dans show ip route ? ; Une interface de sortie down ou un prochain saut injoignable : vérifier show ip interface brief, no shutdown et le câblage.
Que faire si le ping reste sans réponse alors que la route existe des deux côtés ? ; La route retour est absente : ajouter la route symétrique sur le routeur distant.
Que signifie un ping OK depuis le routeur mais KO depuis le poste ? ; La passerelle par défaut est probablement absente du poste : vérifier la configuration IP du client ou l'étendue DHCP.
Pourquoi un ping peut-il être bloqué au-delà du routeur de bordure ? ; À cause d'une ACL ou d'un NAT manquant.
Quelles sont les distances administratives d'une route statique et d'une route OSPF ? ; 1 pour une route statique et 110 pour OSPF, donc à destination égale la statique l'emporte.
Comment faire d'une route statique une route de secours derrière OSPF ? ; Lui donner une distance supérieure à 110, par exemple en ajoutant 200 à la fin de la commande ip route.
